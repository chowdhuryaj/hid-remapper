## Decisions Made

- **Match PowerScribe/PACS by exe only, never hwnd or class** — per the ahk-radiology skill; PS One is multi-window with a per-run GUID class.
- **Radial cancel on process change, not window change** — syngo.via/PACS/browsers bounce focus between their own windows (v0.4.9 lesson).
- **Second tap closes a latched radial menu; a press while any menu is up closes it** — a hand on the mouse has no Escape.
- **Nested menus depth two only (dwell on a door)** — Kurtenbach/Buxton accuracy limit; 9-slot ring is the one exception, for numbered window presets.
- **Simple mode hides pages but keeps their `PANELS` slot** — index semantics unchanged; each action dropdown carries its own `codes` array (`Atlas.ActSelect`/`Atlas.ActCode`) so a row's meaning never depends on which list drew it.
- **Starter packs and the wizard write ordinary bindings via `UpsertBinding`** — no pack/wizard state to unapply; result is editable rows.
- **Migration flags are one-shot settings keys** (`seedPacs061`, `seedPacs061b`, `welcomedVer`) — deleting a seeded item afterwards keeps it deleted.
- **Malformed menus/slices are dropped, not fatal** — a single bad row must never send the config to backup/defaults.
- **"Not saved" banner means a save failed**, not that a slider debounce is pending (`g_CfgSaveFailed`).
- **Single copy per machine via named mutex** — `#SingleInstance` is per path; two copies double-hook the wheel.
