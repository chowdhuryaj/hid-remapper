# RadMapper UI direction

Operate mode: a radiologist should complete one assignment without learning AutoHotkey syntax.

Preserve the incumbent dark navy ground, Segoe UI, compact rectangular controls and pink/cyan/olive identity. Reading-room use favors a quiet ground. Soften the primary pink, improve helper-text contrast, and use color for selection, action and state. The taste profile's useful throughline here is precision with warmth: a short task path, honest status, and careful spacing.

The patched Windows UI keeps the existing engine and direction-table editor. Its setup path is Home → Menus → Edit commands → Assign a button → Practice safely. Four and eight directions have unambiguous labels. Four-way cardinal positions stay fixed when adding diagonals. F1 supplies plain-language guidance.

The Mac HTML mockup explores the next interface: a visual wheel alongside one command editor, a simpler assignment form with optional advanced settings, and a short guide. It is explicitly a design prototype, not a screenshot of the native build. It cannot export an AHK configuration. No extra runtime dependency is introduced into the Windows script.

Preserve native accessibility and focus whenever possible. The web mockup has semantic buttons, labels, visible keyboard focus, keyboard-accessible dialogs, text status and a responsive layout. The current GpGFX widgets need a separate native-controls or UI Automation implementation before equivalent accessibility can be claimed for Windows.
