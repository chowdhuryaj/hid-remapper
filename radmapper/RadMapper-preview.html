From setup to muscle memory.

A short route through RadMapper.

  1. Choose one real task.

    Start with a command you already use, such as moving to the next series. Find its shortcut in your viewer’s settings. Shortcut keys vary between workstations.

  2. Make the menu readable.

    Open Menus → Edit commands. Start with four directions. Add a short label, choose Send keys, then use Rec. Leave unused directions Disabled.

  3. Assign the opening button.

    Choose Assign a button. The patched script fills in the menu and Hold trigger. Choose the program and button, review any replacement warning, then save.

  4. Practice the movement.

    Practice safely never sends a command. Hold to look, move toward a direction, then release. Center and Escape cancel. A tap binding instead selects by resting in a direction.

  5. Check it on Windows.

    Test one assignment in a nonclinical window first, then verify it in your intended viewer. F1 opens help. Ctrl + Alt + Q releases held inputs. The classic settings window offers standard Windows controls.
